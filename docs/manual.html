Textorium 2.0

ユーザーマニュアル / User Guide

Textorium は、文章・コード片・プロンプトを Chrome のローカルストレージに保存し、ポップアップやサイドパネルで呼び出せる拡張機能です。

Textorium is a local-first Chrome extension for saving and reusing snippets and prompt templates from a popup or side panel.

1. インストール / Install

  1. GitHub からリポジトリをダウンロードし、フォルダを展開します。
  2. Chrome で chrome://extensions を開き、デベロッパーモードをオンにします。
  3. 「パッケージ化されていない拡張機能を読み込む」で manifest.json のあるフォルダを指定します。
  4. ツールバーの Textorium アイコンをクリックして起動します。

Download the repository. In chrome://extensions, enable Developer mode, choose “Load unpacked,” and select the folder containing manifest.json. Click the extension icon to open it.

ポップアップ右上の「◨ サイド」からサイドパネルを開くこともできます。Chrome の対応環境で利用してください。

Use “◨ Side” in the popup to request the Chrome side panel (where supported).

2. 登録・編集 / Create and edit

  1. 「+ 新規」で入力欄を開き、本文を入力します。
  2. タイトルは任意です。空欄の場合、本文の最初の有効な行から生成されます。
  3. 必要ならタグ名を入力します。本文に #work のように書いたタグも抽出されます。
  4. 「保存」を押します。本文入力中は Ctrl+Enter（macOS は ⌘+Enter）でも保存できます。

Click “+ New,” enter content, optionally add a title and tag names, and save. The title can be inferred from the content. Inline hashtags such as #work are extracted. Use Ctrl+Enter (Cmd+Enter on Mac) in the content editor to save.

保存済みカードの「編集」からタイトル・本文・タグを変更できます。削除するときは確認ダイアログが出ます。

Use a snippet card’s Edit action to update it. Deletion asks for confirmation.

現行版の制約 / Current limitation: 2.0 の保存・インライン編集処理はタグカテゴリを general として保存します。画面にカテゴリ入力欄がありますが、新規保存時にはその入力値を反映しません。 The current 2.0 editor saves tags under category general; the visible category field is not applied by the new-save handler.

3. プロンプトテンプレート / Templates

本文に {{name}} または {{name:default}} を書くと、穴埋め用の変数として認識されます。

Use {{name}} or {{name:default}} in the content to create fill-in variables.

以下の文章を{{language:英語}}に翻訳してください。
{{text}}
  1. 保存したテンプレートの「展開してコピー」を選びます。
  2. 変数ごとの入力欄に値を入力します（デフォルト値がある場合は初期値として表示）。
  3. プレビューを確認して「コピー」を押します。

Choose “Fill & Copy,” enter the variable values, review the live preview, and copy the rendered text. Variables are text substitutions, not executable code.

4. 検索と整理 / Search and organize

機能 / Feature操作 / Action
検索 / Search上部の検索欄にキーワードを入力して絞り込みます。 / Type into the search box to narrow results.
タブ / Tabs「すべて」「お気に入り」「テンプレート」を切り替えます。 / Switch between All, Favorites and Templates.

5. バックアップ / Backup and restore

  1. 画面右上の ⚙️ を開きます。
  2. 「JSONをエクスポート」でスニペット一覧をファイルとして保存します。
  3. 「JSONをインポート」で保存済み JSON を選びます。
  4. 同じ id のデータは取り込み時にマージされ、追加・更新・無効の件数が通知されます。

Open ⚙️ Settings, export JSON for backup, or import an exported JSON array. Existing IDs are merged, and the app reports added, updated and invalid entries.

重要 / Important: データは Chrome の chrome.storage.local に保存され、別端末と自動同期されません。Chrome プロファイルや拡張機能の削除前には必ずエクスポートしてください。 Data is stored locally in the Chrome profile, not automatically synced. Export backups before removing your profile or the extension.

6. その他の操作と注意 / Settings and notes

ライト / ダークテーマ、日本語 / 英語表示を切り替えられます。⚙️ からサンプルプロンプトを追加できます。

You can switch light/dark theme and Japanese/English display. The Settings menu also offers example prompts.

Textorium はアカウント登録・クラウド同期・テレメトリーを実装していません。一方、機密データ向けの暗号化保管庫ではありません。保存する内容はご自身で管理してください。

Textorium implements no sign-in, cloud sync, or telemetry. It is not an encrypted secret vault; avoid storing highly sensitive credentials.

詳しいデータ形式、テスト・開発手順はリポジトリの README.md と ARCHITECTURE.md を参照してください。
